# 국내 커뮤니티 예약작업 실행 상태

이 폴더는 ChatGPT의 59채널·SEARFin 예약작업이 **실제로 시작했을 때** GitHub에 남기는 기록용입니다.

- `runs/YYYY-MM-DD.json` — 한국시간(KST) 기준 당일 작업 상태
- 기록 없으면 **실행 시작을 확인할 수 없음**. 자동으로 "실패" 또는 "실행 안 함"으로 단정하지 않습니다.
- `status=running`은 진행 중 마지막 확인된 상태이며, 종료 증거가 아닙니다.
- `status=complete`는 당일 보고서 GitHub 재조회·검증까지 성공한 경우에만 사용합니다.
- `status=partial`은 검증된 일부 자료를 실제로 게시했지만 미확인 채널이 남은 경우입니다.
- `status=failed`는 당일 게시에 실패했거나 확인 가능한 게시글이 없어 게시를 완료하지 못한 경우입니다.
- 작업이 중단되면 마지막 상태가 `running`에 남을 수 있습니다. 마지막 `updated_at_kst`가 오래됐다면 **진행 상태 미확인**으로 판정합니다.

상태파일은 예약 작업 실행자만 쓰며 사용자 계정 정보, 로그인 토큰이나 PC 로컬 자료를 저장하지 않습니다.

참고: 이 폴더의 README가 만들어진 것만으로 당일 작업이 시작되었다는 의미는 아닙니다.
